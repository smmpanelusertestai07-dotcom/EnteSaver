# Lone Wolf Arena

An offline 1 vs 1 third-person arena shooter for Android, in the style of mobile battle-royale
"Lone Wolf" modes. Press **START** and you drop straight into a single round against a bot.
No login, no internet, no database: everything (settings, HUD layout, profile, stats) is stored
locally on the phone as JSON.

Built with **Godot 4.7.2** (MIT-licensed, open source, no license key or account needed).

**Ready-to-install APK:** [`apk/LoneWolfArena.apk`](apk/LoneWolfArena.apk) (Android 7.0+, arm64 + armv7, 85 MB).

## Features

- **Match:** 1 round, 1 vs 1 bot (Easy / Normal / Hard), 3:00 timer, shrinking safe zone after
  60 s, countdown, BOOYAH / defeat banner, results screen (kills, damage, headshots, accuracy, XP).
- **Controls (multi-touch):** floating joystick, drag anywhere on the right to look, FIRE button
  that also aims while you drag it (drag-fire), optional left FIRE button, scope (red-dot ADS),
  jump, crouch, reload, 3 weapon slots, medkit, shield wall, grenade, pause.
- **Gunplay:** red-dot crosshair with dynamic spread, per-weapon recoil patterns with recovery,
  bloom, movement/jump spread penalties, crouch/ADS bonuses, hit-scan with head/body/limb
  hitboxes, damage falloff, vest/helmet armor, hit markers, damage numbers, headshot sound.
- **Aim assist:** friction near targets, magnetism while firing, and the "drag headshot" window
  (dragging up while firing near the head sticks to it briefly). Toggle and strength in settings.
- **Weapons:** VIPER AR (auto), THUNDER SG (8-pellet pump), HAWK P9 (pistol).
- **Bot AI:** sight + hearing (gunshots, footsteps), reaction time, tracking error that shrinks
  while it tracks you, strafing, crouch-spam on Hard, weapon choice by range, cover finding,
  healing, shield walls, unstuck logic, navmesh pathing.
- **Custom HUD editor:** drag every button, change size and opacity, reset, save.
- **Settings:** graphics (Smooth / Standard / Ultra), FPS 30/60/90, sensitivity (general, red dot,
  fire-button drag), aim assist, left fire, crosshair color/size/dynamic, volumes, vibration,
  damage numbers, FPS counter.
- **Lobby:** character on a lit stage (drag to rotate), profile with level/XP, editable name,
  match stats, difficulty, bundles (outfits) wardrobe, how-to-play.

## Project layout

| Path | What |
|---|---|
| `autoload/game.gd` | Settings, profile, HUD layout, JSON save, scene switching |
| `autoload/audio.gd` | Sound effects / music players |
| `scripts/fighter.gd` | Shared combat logic (health, armor, weapons, items, hitboxes, movement) |
| `scripts/player.gd` | Camera rig, touch look, drag-fire, recoil, aim assist |
| `scripts/bot.gd` | Bot AI |
| `scripts/hud.gd`, `hud_layout.gd` | In-match HUD and touch routing; default control layout |
| `scripts/arena.gd`, `map_builder.gd` | Match flow, zone, results; arena geometry and colliders |
| `scripts/lobby.gd`, `settings_panel.gd`, `hud_editor.gd` | Menus |
| `scripts/character_model.gd` | Rigged character, animation blending, bundles, held weapon |
| `assets/` | Character, props, textures, audio, fonts, icon (generated by the scripts in `tools/`) |
| `tools/` | Asset generation scripts (Blender/bpy, audio/texture synthesis) and the CI emulator test |
| `tests/` | Unit tests and compile check |

## Build

```bash
godot --headless --path . --import
godot --headless --path . res://tests/run_tests.tscn          # unit tests
godot --headless --path . -- --autotest=sim                    # full headless match simulation
GODOT_ANDROID_KEYSTORE_RELEASE_PATH=... GODOT_ANDROID_KEYSTORE_RELEASE_USER=... \
GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD=... \
godot --headless --path . --export-release "Android" build/LoneWolfArena.apk
```

The Android SDK path and JDK must be set in Godot's editor settings
(`export/android/android_sdk_path`, `export/android/java_sdk_path`). The GitHub Actions workflow
`.github/workflows/lonewolf-arena.yml` does all of this, then installs the APK on an Android
emulator, presses START, plays a few seconds and uploads screenshots and logcat.
