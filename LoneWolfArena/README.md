# Lone Wolf Arena

An offline 1 vs 1 third-person shooter for Android in the style of the "Lone Wolf" duel modes of
mobile battle royales. Press **START** and you play one round against a bot in a container
warehouse. No login, no internet, no database: settings, HUD layout and your profile are stored
on the phone as JSON. Every asset (character, guns, map, icons, sounds, music) is original and
generated by the scripts in `tools/`.

Built with **Godot 4.7.2** (MIT-licensed, open source).

**Ready-to-install APK:** [`apk/LoneWolfArena.apk`](apk/LoneWolfArena.apk) (Android 7.0+, arm64 + armv7).
The game asks for no permissions except vibration (no internet access at all).

## The match

- **Flow:** lobby -> START -> 10 s prep in your spawn alcove behind a red barrier while both
  players pick the round's gun -> "ROUND 1" banner -> 90 s fight -> results.
- **Loadout:** the picked gun + fists, 2 medkits, 2 shield walls, 1 frag grenade, level 2 helmet
  and vest, 200 HP.
- **Guns (both players get the same one):** VIPER AR, WASP SMG, THUNDER SG (pump shotgun),
  BULLDOG LV (lever shotgun), HAWK .50 (hand cannon), FALCON SR (bolt sniper with a full scope).
- **Safe zone:** holds for 25 s, then closes over 40 s to a 4 m circle in the middle of the hall;
  outside it you lose 5, then 10, then 20 HP per second.
- **End:** eliminate the bot for a VICTORY; at time-out the higher HP wins (equal HP is a draw).
  Results show eliminations, damage, headshots, accuracy, time and XP.

## Feel

- **Movement:** run, sprint, walk, crouch, prone and crawl, jump; fall damage from high drops.
- **Aim:** white crosshair that turns red on an enemy, dynamic spread, recoil, ADS red dot and a
  first-person sniper scope. Sticky aim assist: slow-down near a target, tracking, a pull while
  firing and a head stop for drag-up headshots (all adjustable or off in settings). Line of
  sight is required, so the assist never pulls through walls.
- **Damage model:** head / body / limb hitboxes, per-gun head multipliers and damage falloff,
  armour that soaks body and head damage; damage numbers, hit markers, headshot sound.
- **Bot:** sees and hears (shots, footsteps), reacts with a human delay and aim error that
  shrinks while it tracks you, strafes and jump-strafes, keeps the right range for its gun,
  uses cover, heals, drops shield walls, throws its grenade at you behind cover and moves into
  the safe zone as it closes. Easy / Normal / Hard.
- **Animations:** locomotion matched to speed, crouch, prone idle and crawl, jump, reload, pump,
  heal (medkit in hand), throw, weapon swap, hit flinch, death and victory.

## Menus

Lobby with your character, profile (name, level, XP, stats), bundles (outfits), custom HUD
editor (move, resize and fade every button), settings (graphics, frame rate, sensitivities,
aim assist and precision, left fire button, run mode, crosshair colour and size, sound), pause
menu and results screen.

## Fair play (offline)

The game cannot be "hacked" to affect anyone else, but its protections make the common cheats
fail or void the match:
- HP, ammo and items are stored XOR-masked with a checksum, so memory scanners can't find them
  and frozen/edited values are detected.
- A speed hack is caught by comparing the game clock with the wall clock.
- The profile (level, XP, wins) is signed with a device-bound HMAC; an edited file is rejected.
- On Android the game reads its own APK's signing block and compares the certificate with the
  official one (`build_signer.txt`, written by `tools/build_apk.sh`).
- Settings loaded from disk are clamped to their valid ranges.
- Test hooks (`--autotest`, `--shots`) only work from the editor binary, never in an export.
A detection ends the running (or next) match as INVALID with no XP.

## Build and test

```bash
godot --headless --path . --import                                   # first time / after asset changes
godot --headless --path . res://tests/check.tscn                     # every script compiles
godot --headless --path . res://tests/run_tests.tscn                 # unit tests
godot --headless --path . -- --autotest=sim                          # a full headless match
godot --headless --path . -- --autotest=aim                          # aim assist checks
godot --headless --path . -- --autotest=script:res://tests/bot_check.gd     # bot: zone, grenade arc
godot --headless --path . -- --autotest=script:res://tests/anim_check.gd    # animation integration
LW_ROUNDS=6 godot --headless --path . -- --autotest=script:res://tests/flow_soak.gd   # leak check
tools/qa/capture.sh /tmp/shots 1560x720 screens                      # screenshot walkthrough
tools/build_apk.sh                                                   # signed release APK
```

`tools/build_apk.sh` needs the Android SDK and JDK set in Godot's editor settings and a signing
key (see the script header; keys and passwords never go into the repository). The GitHub Actions
workflow `.github/workflows/lonewolf-arena.yml` runs the checks above, exports an APK, installs it
on an Android emulator, presses START, plays a few seconds and uploads screenshots and logcat.
